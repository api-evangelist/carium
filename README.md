Carium is a virtual care management platform delivering advanced remote patient monitoring and health engagement solutions. It integrates bi-directional EHR data, provides intelligent automation, and supports care teams with real-time analytics to improve patient outcomes and operational efficiency across health systems and payors.

**Areas:** Healthcare · Virtual Care · Remote Monitoring · Patient Engagement · Health Tech · Company

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Carium: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
